# いまやることタイマー（継続を前提としないTaskChute）

「使いたいときだけ使う」をコンセプトにした、超ミニマルなTaskChute風タイマーです。
今からやることを所要時間つきで並べると、タイムラインに開始・終了予定時刻が出て、
上から「実行」を押すと1つずつタイマーが回り、全体の終了時刻も見えます。

毎日続ける必要はありません。やりたいときに開いて、並べて、消化するだけ。

## 使い方

1. `index.html` をブラウザで開く（PCでもスマホでもOK）。
2. 下の入力欄に「やること 時間」を入れて **＋**。
   - 例: `買い物 30` → 買い物・30分。
3. 一番上の「やること」の **▶** を押すとタイマー開始。
   - カウントダウンと、その作業の終了予定時刻が出ます。
   - 予定を過ぎると `+1:30` のように赤く超過表示。
4. 終わったら **✓**。次のタスクが実行可能になります。
5. 上部に「残り」と「終了予定（この調子だと終わる時刻）」が出ます。

### まとめて貼り付け（コピペ取り込み）

別のエディタやメモで一覧を書いて、入力欄に **改行ごと貼り付け** すると一括で取り込めます。

```
買い物 30
ゲーム 1h
昼寝 20m
歯みがき 5
```

- 時間の書き方は `30`（分） / `5`（分） / `20m` / `1h` / `1.5h` / `1h30m` / `1時間30分` などに対応。
- 時間が読み取れない行は **名前だけ取り込み**、所要時間は後からタップで設定できます。

### 編集・並び替え

- **名前** や **時間** はタップ（クリック）でその場編集。
- 並び替えは **ドラッグ&ドロップ**（スマホのタッチもOK）、または ハンドルにフォーカスして **Ctrl + ↑/↓**。
- ↺ … 完了したタスクをやり直す / ✕ … 削除
- 「完了を消す」「全消去」 … 片付け用

## データについて

- データはお使いの **ブラウザ内（localStorage）** に保存されます。サーバー不要・オフラインでも動きます。
- 現状、データは **端末ごと** に別々です（スマホとPCで共有はされません）。
- 将来的にスマホ⇄PCで同じデータを見たい場合は、クラウド同期（Supabase など）を
  あとから足せる設計にしてあります。必要になったら拡張してください。

## スマホで使う

- スマホのブラウザでこのファイル（または公開URL）を開き、「ホーム画面に追加」すると
  アプリのように起動できます。
- GitHub Pages 等に置けば、URLを開くだけでスマホ・PCどちらからも同じUIで使えます
  （データ自体は前述のとおり端末ごと）。

## 技術メモ

- 依存ライブラリなし。`index.html` 1ファイルで完結（HTML + CSS + バニラJS）。
- スケジュールは「今」を起点に、実行中タスクの開始時刻と各所要時間を前送りで積み上げて算出。
